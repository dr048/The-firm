# Alder & Co. — Accounting for what's next

A responsive, six-page static website concept for an approachable accounting firm. The site includes Home, Services, About, Who we help, Resources, and Contact pages.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server. No build step or dependencies are required.

## Customize

- Update the firm name, copy, email address, and services in the HTML pages.
- `styles.css` contains the shared responsive visual system.
- `script.js` provides the mobile navigation and dynamic copyright year.
- The contact form uses a `mailto:` action as a no-backend starter. Connect it to a form provider or your own endpoint before production use.

This is a fictional website concept; replace example firm details and review accounting/tax information for your jurisdiction before publishing.
